# Lista de Questões — Pilha em C

Exercícios resolvidos em **C** usando a estrutura de dados **pilha**.

| Questão | Enunciado | Arquivo |
|:-------:|-----------|---------|
| 1 | Converter um número inteiro positivo de decimal para binário | [`questao1.c`](questao1.c) |
| 2 | Verificar se a quantidade de `(` é igual à de `)` numa expressão | [`questao2.c`](questao2.c) |
| 3 | Verificar se uma palavra é um palíndromo | [`questao3.c`](questao3.c) |
| 4 | Calcular uma expressão em notação polonesa reversa (pós-fixa) | [`questao4.c`](questao4.c) |

## Como executar

```bash
gcc questao1.c -o questao1
./questao1
```
